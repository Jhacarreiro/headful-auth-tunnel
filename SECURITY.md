# Security policy

## Supported versions

Security fixes are applied to the latest release line.

## Reporting a vulnerability

Please use GitHub private vulnerability reporting for this repository. Do not open a public issue containing tokens, cookies, credentials, private URLs, browser-profile data, or proof-of-concept details that expose a running tunnel.

The tunnel is intended for trusted LAN or VPN use. Do not expose it directly to the public internet. Use TLS whenever traffic can leave a trusted host, keep the token file mode at `0600`, and use a dedicated browser profile.
